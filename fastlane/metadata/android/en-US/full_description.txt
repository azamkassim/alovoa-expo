OpenCircle is an open-source social and matching client built from the Alovoa mobile codebase. Core discovery, swipe/match, profile and chat features are intended to be available without coin or VIP gates.

The app is designed for an Alovoa-compatible backend operated by the deployment owner. It also provides shareable Cam2Cam video rooms through a configurable Jitsi-compatible provider.

Current MVP navigation:
- Browse
- Swipe
- Social activity
- Cam2Cam
- DMs
- Me/profile

This project does not bypass another app's paid features. It is an independent open-source implementation foundation.
